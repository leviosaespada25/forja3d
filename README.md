# Forja 3D

Convierte fotos en modelos 3D (GLB, STL, OBJ).

- **Reconstrucción con IA:** a partir de hasta 4 vistas (frente, espalda, izquierda, derecha) genera una sola figura con Hunyuan3D-2mv. Las fotos se envían al servicio en Hugging Face.
- **Relieve local:** a partir de una foto, calculado en el navegador sin subir nada.

Abrir: https://leviosaespada25.github.io/forja3d/
